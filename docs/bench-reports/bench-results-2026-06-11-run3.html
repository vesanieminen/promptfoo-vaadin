7 Cross-cutting observations

Skills didn't separate this run

Across the A/B/C sweeps the md_ui_spec skills lead (+2 on the morning Claude-graded run) collapsed to 0 here, and the no-skills baseline posted the top mean (93.4%). The durable read isn't "skills don't help" — it's that a single run can't resolve a 1–2 point gap. Use REPEAT=N before treating any of this as a ranking.

The 480px bug reproduces (3rd time)

Three independent sweeps, the same max-width: 379px chosen by every agent, the same lost narrow-viewport bullets at 480px. This is firmly a benchmark-level signal — worth clarifying the task's narrow-viewport definition before reading the basic_layout spread as an agent skill gap.

Idiom is where points leak, not function

Every app worked; the deductions are idiom. On basic_layout all three reached for plain Div + CSS instead of HorizontalLayout/VerticalLayout; on md_ui_spec all three extend FormLayout rather than Composite<FormLayout>, and the theme variants / ConfirmDialog conventions slip. These are the framework-fluency points the rubric is built to catch.

The SDK hang is non-deterministic and costly

This run hung 4 of 9 solve rows (claude all three; local-mcp one) plus one verifier row — well above the 1–2 of prior runs — and contradicted the "first-problem cold-start" correlate (claude hung on problems 2 and 3 too). Workspaces built and graded fine, but claude's whole solve-side telemetry is gone. Strengthens the case for the pre-warm / idle-watchdog fixes in the hang writeup.

8 Caveats & data gaps

  • Self-grading is total (no Codex) — every grade is Claude-on-Claude. The grading is largely measurement-based (the verifier drives the running app via Playwright), but there's no cross-model anchor this run; take the absolute scores as Claude's own measurement.
  • claude's phase-1 data is missing. All three claude (hosted MCP) solve rows hung — the agent-SDK finished its work but didn't exit, so the per-row timeout reaped each one. Its solve cost ($0) and trace columns are blank. The workspaces were complete and phase 2 graded them 20 / 31 / 46, which are the valid scores — but don't read claude's $12.36 total, or the $61.80 sweep total, as complete.
  • One verdict is a re-grade. md_ui_spec/no-skills's original verify row (eval-6PO) hung after writing its verdict to disk — the same SDK hang, this time on the verifier. A single-row re-grade (eval-0ub) reproduced 46/48 cleanly and is the cited verdict.
  • n = 1 per cell — treat ±1–2 rubric points as noise. This run is itself the evidence: the md_ui_spec skills gap moved 2 → 0 between sweeps.
  • Token columns understate throughput by design — use cost, not tokens, for efficiency (and note claude's is missing).
